---
title: "Mensajes con sticker"
---

Esta referencia describe los eventos de activación y el contenido de la carga del webhook messages de la cuenta de WhatsApp Business para mensajes que contienen un sticker.

El cuerpo del evento contiene directamente el objeto `value` de Meta (`entry[].changes[].value`), como se explica en la [introducción](/webhook/introduccion).

## **Cuando ocurre**

- Un usuario de WhatsApp envía un sticker.
- Un usuario de WhatsApp envía un sticker a través de un anuncio de clic a WhatsApp.

## **Ejemplos**

### **Mensaje con sticker**

Este ejemplo muestra un sticker enviado por un usuario de WhatsApp.

```json
{
  "messaging_product": "whatsapp",
  "metadata": {
    "display_phone_number": "15550783881",
    "phone_number_id": "106540352242922"
  },
  "contacts": [
    {
      "profile": {
        "name": "Sheena Nelson"
      },
      "wa_id": "16505551234"
    }
  ],
  "messages": [
    {
      "from": "16505551234",
      "id": "wamid.HBgLMTY1MDM4Nzk0MzkVAgASGBQzQUQ0N0VFMDA2MTQ0RkJFNkNDNAA=",
      "timestamp": "1750275992",
      "type": "sticker",
      "sticker": {
        "mime_type": "<MEDIA_ASSET_MIME_TYPE>",
        "sha256": "<MEDIA_ASSET_SHA256_HASH>",
        "animated": false,
        "id": "<MEDIA_ID>",
        "url": "<MEDIA_URL>"
      }
    }
  ]
}
```
